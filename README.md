# ペット育成ゲーム（localStorage課題）

## 概要
ブラウザで遊べるシンプルなペット育成ゲームです。
ペットの状態とお世話日記を **localStorage** に保存するので、ページを閉じても続きから遊べます。

## 使用技術
- HTML
- CSS
- JavaScript（jQuery 2.1.3）
- localStorage

## ファイル構成
```
pet-game/
├── index.html            … 画面とJavaScript
├── README.md
├── css/
│   ├── reset.css
│   └── style.css
└── js/
    └── jquery-2.1.3.min.js
```

## 遊び方
1. `index.html` をブラウザで開きます。
2. ペットには「おなか」「ごきげん」「きれい」の3つのバロメータがあります（最初は50〜80のランダム、最大100）。
3. **5秒ごと**に、それぞれのバロメータがランダム（1〜10）に減っていきます。
4. ボタンでお世話をしてバロメータを回復させましょう（+20）。

| ボタン | 増えるバロメータ |
|--------|------------------|
| 🍖 ごはん | おなか |
| ⚽ あそぶ | ごきげん |
| 🧹 そうじ | きれい |

5. ボタンを押すと、画面下の **お世話日記** に「時間」と「お世話の内容」が記録されます（新しい順）。
6. どれか1つでも **0** になると、ペットがいなくなって **ゲームオーバー** です。
7. **「さいしょから」** ボタンで、データを消してはじめからやり直せます。

## localStorageの使い方
| キー | 保存内容 |
|------|----------|
| `pet_status` | バロメータの値とゲームオーバー状態（JSON） |
| `pet_diary` | お世話日記の配列（JSON） |

- `JSON.stringify()` でオブジェクト・配列を文字列にして保存
- `JSON.parse()` で読み込んで元に戻す
- ページ読み込み時に保存データを取り出し、バロメータと日記を表示
- 「さいしょから」では `localStorage.removeItem()` で該当データだけ削除

## 工夫した点
- バロメータが50以下で黄色、20以下で赤色に変化
- ペットは写真をもとにしたSVGイラスト（黒いポメラニアン）
- ペットの表情がバロメータの状態で変わる（にこにこ → こまり顔 → なみだ顔）
- ゲームオーバー時はお世話ボタンが押せなくなる

## 調整できる値（index.html の「設定」部分）
| 定数 | 意味 | 初期値 |
|------|------|--------|
| `MAX` | バロメータの最大値 | 100 |
| `START_MIN` / `START_MAX` | 最初のバロメータの範囲 | 50 / 80 |
| `DOWN_MAX` | 5秒ごとに減る量の最大値 | 10 |
| `UP` | ボタンで増える量 | 20 |
| `INTERVAL` | 減る間隔（ミリ秒） | 5000 |
